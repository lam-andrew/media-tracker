# Design studies

These are frozen reference archives, not active application packages. They contain explicit
source files and built previews only: no credentials or node_modules.

- [Study 01](study-01.zip): soft editorial layout, rounded components, Terracotta default,
  thirteen palettes in Settings, browser-local palette persistence. Saved alternative.
- [Study 02](study-02.zip): leading direction, spatial library, dimensional spines, soft shadows,
  frosted controls, daylight/evening modes, room/gallery/journal and interactive details.

Each ZIP includes `dist/` for a static preview and source for further exploration. Extract
and serve `dist/` with a local HTTP server, or install the source's declared dependencies.
Fonts and covers use external URLs. Study 02's Study 01 comparison link assumes port 3191.
Study 01's included snapshot hashes cover the saved original source files.

Local working previews at capture time:

- Study 01: `/Users/andrewlam/Documents/marqd-design-study-01`, http://127.0.0.1:3191/
- Study 02: `/Users/andrewlam/Documents/marqd-design-study-02`, http://127.0.0.1:3192/

Production v2 components must be implemented in the v2 workspace. Prototype sample-data
behavior, whole-star ratings and generic percentage progress are not production requirements.
